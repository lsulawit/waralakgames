# Brain Buddy 3D — Memory Quest

เว็บเกมจำตำแหน่งแบบ static HTML เปิดได้ทันทีโดยไม่ต้องติดตั้งแพ็กเกจ

## จุดเด่น
- ภาพตุ๊กตาหมี 3D-look แบบ SVG
- แอนิเมชัน idle, กระพริบตา, โบกอุ้งเท้า, ลอยตัว, เอฟเฟกต์เฉลย
- ไม่มีระบบจับเวลาหรือปิดภาพอัตโนมัติ
- เลือกจำนวนภาพ 9 / 12 / 16 / 20
- แตะหมายเลขบนกระดานเพื่อเลือกคำตอบก่อนเฉลย
- คำถามสุ่มโดยไม่ซ้ำจนกว่าจะถามครบ
- สถิติถามแล้ว / ตอบถูก
- Scoreboard A/B/C/D
- Focus Mode
- Fullscreen
- Sound on/off
- Responsive สำหรับมือถือ แท็บเล็ต คอมพิวเตอร์ และจอฉาย

## Deploy
อัปโหลด `index.html` ขึ้น Vercel / Netlify / GitHub Pages หรือเปิดไฟล์โดยตรงได้
