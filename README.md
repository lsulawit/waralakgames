# Brain Buddy — Complete Edition
Created by Waralak Songsang

Features
- Solo and 2–4 team play with custom names
- 6 game modes
- Easy / Normal / Hard / Expert
- Adaptive difficulty
- Combo / bonus scoring
- 5 character packs
- First-play tutorials
- Achievements
- Local game history and progress chart
- Music / multi-effect synthesized SFX
- Multiple character motion styles
- Animated scene transitions
- Full-board answer reveal
- Same-board next-question flow
- Save result card as PNG and share/copy
- Accessibility settings and keyboard shortcuts
- Presenter / Focus mode
- About section with research references

Static single-file app, ready for Vercel.
