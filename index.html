หลักการ & งานวิจัย

คำแนะนำหลังจบรอบอธิบาย “ผลงานในเกมนี้” และเสนอความท้าทายถัดไปแบบเชิงบวก

Working memory

Working memory ใช้สำหรับคงและจัดการข้อมูลชั่วคราว จึงสอดคล้องกับเกมที่ต้องจำภาพ ตำแหน่ง หรือลำดับก่อนตอบ

Visuospatial working memory

เกมที่ต้องจำภาพและตำแหน่งใช้กระบวนการเชิงภาพ-พื้นที่ งานฝึกวิดีโอเกมบางงานพบการพัฒนาผลงานด้าน visuospatial working memory หลังฝึก

Computerised working-memory training

Meta-analysis รายงานการพัฒนาผลงานบนงานฝึกและงานที่ใกล้เคียง จึงเหมาะกับการติดตามความแม่นยำและค่อย ๆ เพิ่มความยากแบบ task-specific

Serious games

Systematic review/meta-analysis พบศักยภาพของ serious games ต่อ working memory และ nonverbal memory ในบางกลุ่ม สนับสนุนการใช้เกมเป็นกิจกรรมฝึกที่มีส่วนร่วม

ผลของ Brain Buddy ใช้ติดตามความก้าวหน้าในโจทย์ของเกม ไม่ใช่คะแนนวินิจฉัยหรือการวัดสติปัญญา โปรไฟล์ การตั้งค่า และสถิติถูกเก็บใน localStorage ของอุปกรณ์นี้
อ้างอิง: Baddeley A. Working memory. Current Biology. 2010; Toril P et al. Video Game Training Enhances Visuospatial Working Memory and Episodic Memory in Older Adults. 2016; Syed M et al. Examining Working Memory Training for Healthy Adults. 2024; Abd-Alrazaq A et al. The Effectiveness of Serious Games in Improving Memory Among Older Adults With Cognitive Impairment. 2022; Li G et al. Meta-analysis of computerised working memory training. 2026.

วิธีเล่น

กติกาหลักสั้น ๆ: ดู → จำ → ตอบ → ดูเฉลย แล้วค่อยไปข้อต่อไป

1. 👀 สังเกต

ดูภาพ สี รายละเอียด และตำแหน่งบนกระดานให้ครบ

2. 🧠 จดจำ

ใช้วิธีจำที่ถนัด เช่น จำเป็นแถว เป็นคู่ หรือจัดกลุ่มภาพ

3. 🎯 ตอบโจทย์

แต่ละโหมดจะให้ทายตำแหน่ง หาคู่ หาสิ่งที่หาย สังเกตการสลับ/เปลี่ยน หรือจำลำดับ

4. ✨ ดูเฉลย

เฉลยจะแสดงคำตอบชัดเจน จากนั้นกดไปข้อต่อไปตามจังหวะของคุณเอง

💡 เริ่มอย่างไรดี?

ครั้งแรกแนะนำ Quick Play ซึ่งเริ่มที่ 2×2 และไม่จับเวลา เมื่อรู้สึกคล่องค่อยเปลี่ยนเป็น 3×3 หรือเปิด Adaptive Difficulty
